Triggers

Choose what causes stub evaluation to run automatically
When enabled, ItemAdded / ItemRemoved / ItemUpdated events trigger stub evaluation. Disable this if you only want processing via scheduled tasks or folder watching.
When enabled, creates FileSystemWatchers on directories so filesystem changes (Created / Deleted / Renamed) trigger stub evaluation. Disable this to avoid per-folder watchers; processing can still run via library events or scheduled tasks.
If both triggers above are disabled, stub processing only runs when you execute the Scan and Hide Disc Stubs scheduled task, manually or on its own schedule.
